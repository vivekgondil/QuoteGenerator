About This Tool

A browser-based quoting tool. Load your price list once, search and build a quote, then export an email-ready table — all processed locally, no server round-trips.

Core Features

  • Instant Search: Price list is loaded into memory for sub-second lookups across every uploaded catalog.
  • No-Rebate Lock: SKUs flagged as "No Rebate" (NR) have discounting disabled, preventing accidental over-discounting.
  • Multi-Year Discount Split: Give a SKU different discounts per year across a 3-year breakup without duplicating it or inflating the quantity/total.
  • Saved Quotes: Save, duplicate, search, export/import, and bulk-delete named quote baskets so you can jump between deals without losing work.
  • Email-Ready Output: Generate a quote and copy a formatted HTML table straight into Outlook or Gmail, with tax and grand total calculated automatically.
